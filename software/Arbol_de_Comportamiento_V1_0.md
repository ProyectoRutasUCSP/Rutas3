# Árbol de Comportamiento V1.0 - Proyecto PedroBot

El código fuente de esta versión (incluyendo modelos 3D y mapas pesados de Gazebo

**🔗 [Descargar la Versión V1.0 (.zip desde Google Drive)](https://drive.google.com/drive/folders/1EqVJf4HeBFqgDDfc-mynCGfGVp1I9DTR?usp=sharing)**

---

### Instrucciones de Ejecución para la Evaluación

1. Descargue el archivo `.zip` desde el enlace anterior.
2. Extraiga la carpeta `ensamble_urdf_ros2` y colóquela dentro de la carpeta `src` de su espacio de trabajo de ROS 2.
3. Compile el paquete desde la raíz del espacio de trabajo:
    - source install/setup.bash
    - ros2 launch ensamble_urdf_ros2 sistema_completo.launch.py
